# Baldos 101 Guide for Folding Proteins
I tried to do it as simple as possible, but if you have any questions, please ask me!
I recomend ussing it in a Jupyter notebook, the example is in `The_Fate_of_Baldo.ipynb`, but you can also run it in a python script if you prefer. Just make sure to follow the instructions.

# Cloning the repository
First, you need to clone the repository and navigate to the folder:

```bash
git clone 
cd AlphaBald
```

# Installing the dependencies
You need to install the dependencies, do it with **CONDA**:
```bash
conda create -f environment.yml
conda activate AlphaBald
```
Once you have the environment activated, you can run the notebook or the script.

# Running the notebook
Get inside of `The_Fate_of_Baldo.ipynb` and run the cells, there's instructions in the notebook, but if you have any questions, please ask me!
